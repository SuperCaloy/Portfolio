# Project Glossary

## UI/UX Terms
- **Double-Bezel (Doppelrand):** Nested architecture for cards. Outer shell with light border and background, inner core with highlight and smaller border-radius.
- **Asymmetrical Bento:** CSS grid layout breaking monotony with varying card spans, collapsing cleanly to single column on mobile.
- **Ethereal Glass:** Dark Mode theme. OLED black backgrounds, vantablack cards, radial mesh gradients.
- **Soft Structuralism:** Light Mode theme. Silver-grey/white backgrounds, airy floating components, soft diffused shadows.

## Backend Terms
- **Laravel Specialist Standards:** PHP 8.2+, eager loading `::with()`, API Resources, strictly typed properties.
- **OTP Salting & Hashing:** Storing admin OTPs using `Hash::make()` and validating via `Hash::check()` rather than plaintext.
